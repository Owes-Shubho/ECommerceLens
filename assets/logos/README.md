# Logos

| File | Use |
|---|---|
| `ecommercelens-icon.png` (1024 px), `-512`, `-64` | App icon: white cart, magnifier and rising bars on the logo blue `#0064FC`. Favicon, app icon, next to the wordmark. |
| `ecommercelens-wordmark-light-bg.png` | "ECommerce" in dark ink `#0E1726`, "Lens" in logo blue. For light backgrounds. |
| `ecommercelens-wordmark-dark-bg.png` | "ECommerce" in white, "Lens" in logo blue. For dark backgrounds. |
| `source/` | The original files as delivered, kept unchanged for reference. |

All PNGs have transparent backgrounds. The cleaned versions fix the originals: the icon's dark smudge is removed and its blue is solid and even; the wordmark letters are fully opaque and cropped tight; a dark-text wordmark was added because the original only works on dark backgrounds.

The app's brand colour (`lens`) is `#005FF0`, one step darker than the logo blue so it passes 4.5:1 as text. App copies of these files are in `frontend/public/brand/`.
