# Assets

Media files for the project: diagrams, images, report and presentation files. Written documentation (Markdown) lives in `docs/`; this folder holds the files those documents and the final report point to.

| Folder | What goes here | Examples |
|---|---|---|
| `diagrams/` | Architecture, data-flow and pipeline diagrams (keep the editable source next to the export) | `system-architecture.drawio`, `system-architecture.png`, `ai-pipeline.svg` |
| `images/` | General images used in the README, docs or report | `dataset-relationships.png` |
| `screenshots/` | Screenshots of the running app, page by page | `overview-light.png`, `assistant-dark.png` |
| `charts/` | Exported charts and figures from notebooks and experiments | `lstm-vs-gru-test-rmse.png`, `token-savings.svg` |
| `reports/` | Report files (drafts and final, PDF / DOCX) | `ECommerceLens-report-v1.pdf` |
| `presentations/` | Slide decks for the viva and demo | `ECommerceLens-viva.pptx` |
| `logos/` | The app's logo and icon files | `lens-mark.svg` |
| `videos/` | Demo recordings and GIFs | `demo-assistant.mp4` |

Naming: lowercase, words joined with hyphens, a version or date suffix where there are drafts (`report-v2.pdf`, `overview-2026-10-21.png`).
Keep files under about 20 MB each; larger videos are better linked (YouTube, Drive) from the README than committed.
